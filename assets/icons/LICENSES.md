# Icon sources

`ot-icons.svg` is an SVG sprite built for this project from:

- **Lucide** v0.452.0 (UI icons, ISC licence, reproduced below), redrawn at stroke-width 1.75.
- **Simple Icons** v13.15.0 (Instagram, LinkedIn, Facebook, WhatsApp marks, CC0-1.0). The brand marks remain trademarks of their owners and are used only to link to Open Tickets' own social profiles.

The same sprite is inlined at the top of every page (`src/partials/icons.html`) so `<use href="#i-…">` works without extra requests and from any page depth. Icon ids: `i-events`, `i-faq`, `i-support`, `i-account`, `i-pages`, `i-customers`, `i-search`, `i-globe`, `i-pin`, `i-clock`, `i-calendar`, `i-ticket`, `i-chat`, …
